ヒント
  • まず ' を入れてエラーを出し、SQLの構造を推測してみましょう。
  • is_public = 1 の条件を、OR と -- で無効化できないでしょうか?
  • UNION SELECT を使うと、別のテーブルの結果を同じ表に混ぜられます。列数(ここでは4列)を合わせる必要があります。
  • テーブル名・列名が分からないときは、SQLite の sqlite_master テーブルを調べます。
  • accounts テーブルのユーザー名とパスワードを表示させてみましょう。
なぜ危険か / 本来どう直すか

検索語がSQL文に連結されているため、攻撃者は WHERE 条件を崩して非公開データを読んだり、UNION で無関係なテーブル(認証情報など)を引き出したりできます。エラーメッセージの表示は、攻撃者にDB構造のヒントを与えます。

対策は プレースホルダ です。LIKE でも db.Query("SELECT ... WHERE is_public = 1 AND name LIKE ?", "%"+q+"%") のように、ワイルドカード込みの値をバインド変数として渡します。さらに、DBユーザーの権限を最小化し、エラー詳細はログにのみ残します。
